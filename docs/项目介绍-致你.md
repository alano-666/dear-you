# 《致你》Dear You — 项目介绍

> **世界都在催你开口,它只是安静地记得你。**

一款**没有聊天框**的陪伴型 AI:你把生活交给它,它每天、每周给你写一封信。

---

## 一、我们想解决的问题

**人的记录困境**:我们都想记住生活,但坚持不了日记——门槛高、有压力、写几天就放弃了。照片倒是拍了很多,但躺在相册里再也不会被打开,更不会有人告诉你"你的生活正在发生什么"。

**陪伴产品的范式问题**:现有的 AI 陪伴(Replika、星野等)都是聊天框形态——**你必须主动找话说,它被动回应**。你是在服务它,而不是它在陪你。而人真正渴望的陪伴感,是"有人记得你的生活",不是"有人陪你说话"。

**一句话:世界已经够吵了。我们需要一个不要求我们开口、却一直记得我们的存在。**

---

## 二、产品是什么

一条五步循环,没有一步需要你"会写"或"会说":

```
① 提交        拍张照片 / 写几句话 / 传段视频——零压力,30 秒完成
② 识别        AI 看懂素材,写下一句"观察"(描述 + 标签 + 情绪)
③ 时间线      所有记忆汇成一条流动的"河流",按时间陈列
④ 写信        每天一封日信、每周一封周信,主动送到你面前
⑤ 发现        信里告诉你:你的生活正在发生什么变化
```

**关键约束(刻意为之)**:没有聊天框——这是定位,不是缺失。它不是让你输入命令的工具,而是一个替你记得的角色。

---

## 三、核心亮点:"AI 记得你自己都忘了的东西"

写信只是形式,**记得才是魔法**。信中最动人的部分,是"三类发现":

| 发现类型 | 它做什么 | 真实生成示例 |
|---|---|---|
| **对比** | 和过去的你比 | "9 天前你跑 3 公里,这一周两次都到了 5 公里。" |
| **回响** | 你很久前说过的话,今天应验了 | "八月你写下『想把日子过慢一点』。你大概没想到,它最后落在了傍晚的操场和书页上。" |
| **缺失** | 很久没出现的东西,温柔地提醒 | "吉他已经 17 天没被弹响了。它不催你,那段熟悉的曲子还在原地,等你哪天回去。" |

**为什么这是护城河**:数据统计(跑了多少公里)谁都能做;但"回响"和"缺失"需要**持续的记忆 + 主动的理解**——这是所有替代品做不到的。现场演示时,观众亲眼看到自己都忘了的话被原样还回来——那一刻不需要任何解释。

---

## 四、与替代品的区别

| 替代品 | 它的做法 | 我们的不同 |
|---|---|---|
| 日记 App(心光、Day One) | 要你自己打开、自己写 | 交出去就行,而且有"回信" |
| AI 聊天陪伴(Replika、星野) | 你必须找话说,它被动回应 | 它主动来;有真实记忆库,记得你交过的每样东西 |
| 相册"回忆"(Apple / Google) | 把老照片翻出来播放 | 不只是回放,是"理解"之后写成信 |
| 社交平台 | 你要表演,还要等点赞 | 没有观众、没有评判,只有一个读者 |

## 五、技术实现(全部真实,非概念演示)

| 层 | 实现 |
|---|---|
| 全栈 | Next.js 16(App Router)+ TypeScript,已部署 Vercel,**线上可访问** |
| 视觉识别 | 智谱 glm-4v-flash(免费):照片/视频帧 → 结构化观察 |
| 信件生成 | 百智云网关 glm-5.3-flash(Anthropic 兼容) |
| 模型抽象层 | `lib/llm.ts` 统一封装——换任何模型只改一个文件 |
| 记忆存储 | 浏览器 localStorage + 客户端图片压缩/视频抽帧 |
| **隐私设计** | **服务端不存任何用户数据**——不落盘、不缓存、日志不打印内容 |
| 界面 | 手机/桌面自适应(手机底部 Tab,桌面顶部导航);信件/记忆全部留在本地 |

**可靠性工程**(为现场演示做的保障):

- 稳定性实测:连跑 5 次周信,**JSON 合法率 5/5、三类发现齐全 5/5、0 幻觉引用**
- 断网/服务不可用:**1 秒内快速失败**,自动切换内置备用周信,演示不中断
- 识别失败不阻塞:素材照常流入时间线,支持稍后重试

## 七、现场演示流程(3–5 分钟)

1. **开场**:打开产品——不是聊天框,是三个提交入口,"今天,有什么想交给我的?"
2. **提交**:现场拍一张照片 → "AI 正在看……" → 记忆流入河流
3. **回望**:滚动 30 天的记忆——它全都记得
4. **读信**:打开今天的信,逐字浮现,引用刚才交的照片,点击可跳回河边
5. **高潮**:切换"本周的信"——三类发现(对比 / 回响 / 缺失)逐一浮出
6. **回应**:点一下"被戳中了",它温柔回一句话
7. **收尾**:三种送达方式(微信 / 邮件 / 实体信)→ "明天见"

---

## 八、这个 Demo 要证明什么

1. **用户愿不愿意把真实生活交给 AI**(现场:观众是否愿意用自己手机的照片试)
2. **"被发现"的惊喜感 > 隐私冒犯感**(现场:看到"发现"时的第一反应)
3. **打动人的是信件的质量,不是功能的多少**(现场:观众是夸"信写得好",还是问"还有什么功能")

**观察信号**:观众开始分享自己的故事,而不是问功能细节——情感共鸣就成立了。
